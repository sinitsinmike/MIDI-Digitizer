# MIDI Digitizer

**MIDI Digitizer** --- электронный музыкальный контроллер на базе
Arduino, предназначенный для игры касанием по поверхности дигитайзера с
преобразованием положения пальца в MIDI-ноты.

Проект включает поддержку ладов/гамм, MIDI-выхода, энкодера с кнопкой,
меню настроек, профилей и арпеджиатора.

> **Примечание:** проект находится в разработке. Конкретные распиновка,
> модель дисплея и электрические параметры зависят от аппаратной ревизии
> и текущей версии прошивки.

## Возможности

-   Игра нот касанием по дигитайзеру.
-   Преобразование положения пальца в ноты выбранного лада/гаммы.
-   Поддержка ладов с различным набором нот.
-   MIDI-выход для подключения внешнего синтезатора, MIDI-интерфейса или
    другого MIDI-устройства.
-   Обработка `Note On` и `Note Off`.
-   Арпеджиатор.
-   Меню настроек.
-   Управление параметрами поворотным энкодером.
-   Кнопка энкодера для выбора и подтверждения.
-   Сохранение настроек в профили.
-   Отображение текущих параметров и состояния на дисплее.
-   Настройка гистерезиса положения пальца.

## Принцип работы

Пользователь проводит пальцем по поверхности дигитайзера. Контроллер
определяет положение пальца, преобразует его в музыкальную позицию,
выбирает ноту согласно выбранному ладу и отправляет MIDI-сообщение.

``` text
Палец
  ↓
Дигитайзер
  ↓
Определение позиции
  ↓
Выбор ноты выбранного лада
  ↓
MIDI Note On / Note Off
  ↓
Синтезатор / MIDI-интерфейс / компьютер
```

### Лады и расстояние между нотами

Следует различать **физическое положение ноты на поверхности** и
**музыкальный интервал между нотами**.

В выбранном ладу соседние ступени могут отличаться на полутон или тон.
Алгоритм преобразования координаты дигитайзера должен однозначно
определять границы нот.

Изменение этого алгоритма может изменить физическое расстояние между
срабатывающими нотами и поэтому должно проверяться отдельно от изменений
меню и MIDI.

## Органы управления

### Дигитайзер

Основной игровой контроллер. Перемещение пальца по поверхности выбирает
музыкальную позицию.

### Энкодер

Поворот энкодера используется для перемещения по меню и изменения
выбранного значения.

### Кнопка энкодера

Кнопка используется для выбора или подтверждения пункта меню. Назначение
короткого и длительного нажатия зависит от версии прошивки.

## Дисплей

На основном экране отображается текущее состояние прибора и основные
параметры.

В меню дисплей используется для выбора параметров, отображения значений,
выбора профиля и сохранения настроек.

### Profile

Профили предназначены для хранения наборов настроек прибора.

В интерфейсе используется обозначение вида:

`Profile#N`

При работе с профилями важно различать:

-   номер профиля, выбранный в меню;
-   фактически активный профиль;
-   профиль, из которого параметры были загружены;
-   профиль, в который были сохранены параметры.

Поведение нумерации и отображения профиля является частью прошивки и
может отличаться между RC-версиями.

## MIDI

MIDI Digitizer предназначен для управления внешними MIDI-устройствами.

Типовой поток:

``` text
MIDI Digitizer
     │
     │ MIDI OUT
     ▼
MIDI IN внешнего устройства
     │
     ├── синтезатор
     ├── звуковой модуль
     ├── MIDI-интерфейс
     └── компьютер
```

При выборе ноты контроллер формирует `Note On`. При уходе пальца с
активной позиции или переходе на другую ноту предыдущая нота должна
получать соответствующий `Note Off`.

Конкретный MIDI-канал и дополнительные MIDI-параметры определяются
текущей прошивкой.

## Питание

Контроллер требует внешний источник питания, соответствующий конкретной
аппаратной ревизии.

Перед подключением необходимо проверить:

-   напряжение;
-   полярность;
-   тип разъёма;
-   допустимый ток.

**Не подключайте неизвестный источник питания без проверки электрической
схемы конкретной ревизии.**

## Меню

Типовая логика управления:

-   **поворот энкодера** --- перемещение или изменение значения;
-   **короткое нажатие** --- выбор/подтверждение;
-   **длительное нажатие** --- действие, назначенное текущей прошивкой.

Набор пунктов меню может изменяться между RC-версиями.

## Профили настроек

Профиль позволяет хранить отдельный набор параметров, например:

-   лад;
-   диапазон нот;
-   MIDI-настройки;
-   параметры арпеджиатора;
-   гистерезис;
-   другие параметры, предусмотренные прошивкой.

После изменения логики профилей рекомендуется проверять полный цикл:

``` text
выбрать профиль
      ↓
изменить параметры
      ↓
сохранить
      ↓
выключить питание
      ↓
включить питание
      ↓
проверить загруженный профиль
```

## Гистерезис

Гистерезис используется для предотвращения нежелательного переключения
между соседними нотами при небольших изменениях положения пальца.

Большой гистерезис задерживает переход на соседнюю ноту. Нулевой
гистерезис позволяет переключаться непосредственно при достижении
границы.

**Гистерезис не должен сам по себе изменять геометрическое расстояние
между нотами.** Если расстояния изменились, следует проверять алгоритм
преобразования координат в ноты.

## Арпеджиатор

Проект содержит режим арпеджиатора, который преобразует сыгранные ноты в
последовательность MIDI-нот согласно настройкам текущей прошивки.

## Прошивка и RC-версии

Проект развивается итерационно. В репозитории могут находиться
экспериментальные и release-candidate версии прошивки с изменениями
MIDI, профилей, меню, энкодера и алгоритмов дигитайзера.

При сравнении версий рекомендуется сохранять предыдущую рабочую прошивку
и проверять изменения по одному.

## Что проверять после изменения прошивки

-   равномерность расположения нот;
-   переходы между полутонами и тонами;
-   правильность выбранного лада;
-   отсутствие пропущенных нот;
-   отсутствие двойного срабатывания;
-   `Note On`;
-   `Note Off`;
-   гистерезис;
-   выбор профиля;
-   сохранение профиля;
-   загрузку профиля после перезапуска;
-   отображение активного профиля;
-   энкодер;
-   короткое и длительное нажатие;
-   арпеджиатор.

## Разработка

Проект предназначен для Arduino IDE.

Перед загрузкой прошивки:

1.  Откройте соответствующий `.ino` файл.
2.  Выберите используемую плату.
3.  Выберите COM/USB-порт.
4.  Проверьте необходимые библиотеки.
5.  Соберите проект.
6.  Загрузите прошивку.
7.  Выполните функциональную проверку.

Рабочую версию желательно сохранять отдельно перед экспериментальными
изменениями.
